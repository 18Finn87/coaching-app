# Coaching App

Private App für Krafttraining und Coaching (Coach + Athletinnen/Athleten).

- Planung: [docs/00-planung-version-1.md](docs/00-planung-version-1.md)
- Technik: Next.js (statischer Export), TypeScript, Tailwind CSS, Supabase
- Veröffentlichung: GitHub Pages

## Lokal starten

```bash
npm install
npm run dev
```

Dann im Browser `http://localhost:3000` öffnen.

## Sicherheit

Keine Passwörter, Schlüssel oder `.env`-Dateien ins Repo. Geheimnisse liegen nur im Supabase Vault bzw. in den Supabase-Einstellungen.
